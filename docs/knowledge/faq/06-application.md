# Foire Aux Questions : L'Application et l'Assistant IA

Voici les questions les plus fréquentes sur ce thème.

### Q : Faut-il télécharger PLEINGAZ sur le Play Store ou l'App Store ?
**R :** PLEINGAZ est une application web (PWA). Vous n'avez rien à télécharger sur les stores. Il suffit d'aller sur notre site web et de cliquer sur "Ajouter à l'écran d'accueil" depuis votre navigateur.

### Q : L'application consomme-t-elle beaucoup de données internet (Mo) ?
**R :** Non, l'application est conçue pour être très légère. Une fois chargée, elle fonctionne même avec une connexion lente (Edge/3G).

### Q : Comment marche l'assistant IA de l'application ?
**R :** L'assistant est une intelligence artificielle entraînée pour comprendre vos besoins en gaz. Posez-lui des questions naturellement, comme vous le feriez avec un humain.

### Q : Est-ce qu'un humain lit mes messages avec l'IA ?
**R :** Non, l'IA répond de manière autonome. Un conseiller humain ne lira la conversation que si vous demandez explicitement à être transféré au service client.

### Q : L'IA comprend-elle le Pidgin ou le Camfranglais ?
**R :** Oui, notre assistant est formé pour comprendre le français, l'anglais, et les expressions locales courantes au Cameroun liées à l'achat de gaz.

### Q : Pourquoi l'IA ne me donne pas le prix d'un produit que j'ai demandé ?
**R :** Si l'IA ne vous donne pas de prix, c'est que l'information n'est pas disponible dans la base de données officielle. L'IA a interdiction stricte d'inventer des prix.

### Q : Peut-on utiliser la commande vocale avec l'assistant ?
**R :** La fonctionnalité de saisie vocale dépend de votre clavier de téléphone. Vous pouvez dicter votre message avec le micro de votre clavier (Google Voice/Siri).

### Q : L'assistant me dit qu'une boutique est ouverte mais elle est fermée.
**R :** Les horaires sont gérés par les distributeurs. Si un distributeur a oublié de signaler sa fermeture exceptionnelle, signalez-le nous pour que nous corrigions l'information.

### Q : L'application fonctionne-t-elle sur ordinateur ?
**R :** Oui, PLEINGAZ est responsive et s'adapte parfaitement à l'écran d'un ordinateur, d'une tablette ou d'un smartphone.

### Q : L'IA peut-elle créer mon compte pour moi ?
**R :** Non, pour des raisons de sécurité, l'IA vous guidera vers la page d'inscription mais ne peut pas manipuler votre numéro de téléphone à votre place.

### Q : Peut-on commander par WhatsApp sans passer par l'appli ?
**R :** Oui, le pilote inclut un numéro WhatsApp où vous pouvez discuter. Un agent humain (ou l'IA, selon la phase) prendra votre commande et créera votre compte en arrière-plan.

### Q : Mon application s'est figée, que dois-je faire ?
**R :** Actualisez la page de votre navigateur. Vos données en cours (comme le contenu de votre panier) sont sauvegardées.

### Q : L'IA peut-elle annuler ma commande toute seule ?
**R :** L'IA ne fera jamais d'action sensible sans vous demander une confirmation stricte ("Êtes-vous sûr de vouloir annuler ?").

### Q : Où trouve-t-on la liste des quartiers desservis ?
**R :** Il n'y a pas de liste statique. Tapez simplement le nom de votre quartier dans la barre de recherche ou dites-le à l'IA, le système vérifiera la couverture.

### Q : Comment savoir si la réponse de l'IA est fiable ?
**R :** L'IA utilise exclusivement des données validées par PLEINGAZ. Lorsqu'elle donne un stock, elle précise toujours de quand date l'information (ex: "Confirmé il y a 5 minutes").

### Q : Puis-je donner une note à l'application ?
**R :** Nous serions ravis d'avoir votre retour ! Vous pouvez laisser un commentaire dans la section "Avis et Améliorations" du menu.

### Q : L'application marche-t-elle la nuit ?
**R :** L'application est disponible 24h/24 et 7j/7. Cependant, la possibilité d'acheter dépend des horaires des distributeurs de votre zone.

### Q : L'IA s'est trompée, comment le signaler ?
**R :** Si la réponse de l'IA vous semble incorrecte, dites-lui "Tu te trompes" ou demandez à parler à un conseiller humain.

### Q : Puis-je partager une boutique sur Facebook ou WhatsApp ?
**R :** Oui, chaque boutique a un bouton "Partager" permettant d'envoyer le lien de la boutique virtuelle à vos amis.

### Q : Qui développe PLEINGAZ ?
**R :** PLEINGAZ est une solution camerounaise développée pour faciliter l'accès au gaz domestique de manière fiable et transparente.
